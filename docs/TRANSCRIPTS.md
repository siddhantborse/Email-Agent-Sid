# Example transcripts

Four emails, one per lane, each traced through every step of the
pipeline. Generated by `python examples.py` -- this file is committed
output from an actual run, so it can be read without an API key.

The columns that matter are `2. SORT` (what the model *suggested*) and
`4. DECIDE` (what the deterministic layer *settled on*). Where those two
differ, the `raised:` lines say which rule moved it and why.

One caveat worth stating, since these are live model calls: the
SILENT/NOTIFY/ASK boundary is genuinely fuzzy and individual emails near
it can land differently between runs. `y01` sorted NOTIFY in the recorded
run and ASK in a later one -- over-cautious, which costs a glance and
nothing else. These four are an illustration of the mechanism; the
measurement lives in `eval.py` and `calibration_eval.py`, over the whole
corpus.
